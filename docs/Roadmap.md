# Product Roadmap

---

## Phase 1 — Foundation

* Authentication
* User Profile
* Settings
* Project Setup

**Goal:** Build the core application foundation.

---

## Phase 2 — Bluetooth Mesh

* Bluetooth Permissions
* BLE Discovery
* Nearby Devices
* Nearby Users

**Goal:** Enable offline device discovery and mesh communication.

---

## Phase 3 — Communication

* One-to-One Chat
* Group Chat
* File Sharing
* Offline Sync

**Goal:** Support reliable offline messaging and data synchronization.

---

## Phase 4 — Campus Services

* Department Discovery
* Office Discovery
* Campus Directory
* Indoor Navigation

**Goal:** Help users discover and navigate campus resources.

---

## Phase 5 — Academic Features

* Attendance
* Attendance History
* Faculty Broadcast

**Goal:** Simplify academic workflows.

---

## Phase 6 — Safety & Engagement

* Emergency SOS
* Events
* Announcements
* Notifications

**Goal:** Improve campus communication and safety.

---

## Phase 7 — Administration

* Admin Dashboard
* User Management
* Analytics
* Reports
* System Settings

**Goal:** Provide complete campus administration tools.

---

## Phase 8 — Release

* Performance Optimization
* Testing
* Security Review
* Deployment

**Goal:** Prepare the platform for production release.
